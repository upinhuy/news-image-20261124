3 top stories plus a 47-story hour-by-hour timeline in UTC order, with a
markets-at-the-close strip — 50 stories in total, drawn from AP, Reuters,
BBC, AFP, Politico, UEFA, Al Jazeera, The Kyiv Independent, UN News, WHO
and others.

## How it works

`draw.py` (Python + PIL, run once by the author) draws `entry.png`
(1024×1024, deterministic). `main.ts` (Node standard library only) copies
the committed `entry.png` to the output directory — no rendering at
runtime.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
